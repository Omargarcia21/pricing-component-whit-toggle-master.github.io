# Solución al Desafío de Frontend Mentor: Componente de Precios con Botón Switch

![Badge](https://img.shields.io/badge/Estado-Completado-brightgreen)  
Este es mi solución al desafío **Pricing Component with Toggle** de Frontend Mentor. El objetivo era crear un componente de precios con tres tarjetas que muestren planes mensuales y anuales, junto con un botón switch para alternar entre ambos.

**Desafío de Frontend Mentor:** [Pricing Component with Toggle](https://www.frontendmentor.io/challenges/pricing-component-with-toggle-8vPwRMIC)

## Descripción del Proyecto

Este proyecto consiste en un componente de precios que muestra tres planes: **Básico**, **Profesional** y **Maestro**. Cada tarjeta incluye:

- El nombre del plan.
- El precio mensual o anual (según la selección del usuario).
- Una lista de características incluidas en el plan.
- Un botón de "Leer más".

La funcionalidad principal es un **botón switch** que permite alternar entre precios mensuales y anuales. Cuando el usuario cambia el switch, los precios y la etiqueta (Monthly/Annually) se actualizan dinámicamente usando JavaScript.

## Tecnologías Utilizadas

- **Lenguajes de Programación**: HTML, CSS, JavaScript.
- **Metodologías CSS**: BEM (Block Element Modifier) para la organización del código CSS.
- **Diseño Responsivo**: Compatible con dispositivos móviles, tablets y desktop.

## Instrucciones de Instalación y Uso

Este proyecto es una página web estática, por lo que no requiere instalación.
